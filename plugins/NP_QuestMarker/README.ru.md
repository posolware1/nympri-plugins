# NP_QuestMarker

## Название

Мигающий «!» у цели задания.

## Версия

1.1 (`@plugindesc`).

## Назначение

Пока переменная задания в диапазоне из `NP_QuestMarker.TARGETS`, на текущей карте рисуется мигающий «!»:

- На NPC или клетке текущего этапа, если этап на этой карте.
- Иначе на двери, выходе или узле карты мира (Map003), который встроенная таблица переходов считает дорогой туда.

Значок прячется вместе с NPC. Пустая страница, прозрачность или исчезновение убирают его сразу, и он возвращается, когда персонаж появляется. Невидимые переходы и координатные выходы всё равно считаются целью. Прогресс заданий плагин не меняет, только показывает, куда идти.

## Порядок загрузки

После `NP_AutoSave`, перед `NP_FastBattle`. `NP_QuestTabs` и `NP_YarizoQuest` рассчитывают, что таблица меток уже есть.

## Параметры

- **Enabled** `true`.
- **Option Label** `Метки заданий` — пустое значение прячет пункт настроек.
- **Color** `#ffe040`.
- **Font Size** `34`.

## Требования

Windows, **Alpha 0.80j**. Из скачанного ZIP запустите `install.bat` и укажите папку `www` игры. Категории в общем README — не порядок загрузки.

## Установка

Скопируйте `NP_QuestMarker.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_QuestMarker.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_QuestMarker/` в этом репозитории.

## Скриншоты

Снимка нет. У плагина нет своего экрана, либо в отобранных кадрах его не видно. Позже сюда можно положить только настоящий кадр игры, не макет.
