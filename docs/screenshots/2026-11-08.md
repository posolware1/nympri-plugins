# Frames from 2026-11-08

A local Linux copy of the game was started in NW.js 0.48.4. Case aliases were added for the original game’s own mixed-case paths so that copy could reach the menus. Those aliases are not part of this pack, and this is not official Linux support. The game was not checked on Windows. Language, audio, Yarizo, and the rest of play were not tested.

Save file 15 was loaded for the allocation screen, the pause menu, and the options window. The title-bar crop was taken before that save was loaded.

Each file is a geometric crop of a captured WebP, then converted to PNG. Nothing was redrawn. Sizes are the cropped results. The source frame was 1280×800; the crop box is left, top, right, bottom.
