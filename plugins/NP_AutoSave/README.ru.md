# NP_AutoSave

## Название

Два чередующихся автосохранения.

## Версия

1.1 (`@plugindesc`).

## Назначение

В списках сохранения и загрузки сверху появляются две строки, файлы 21 и 22, они пишутся по очереди. Их можно загрузить. Перезаписать вручную нельзя. Слоты 1–20 не трогаются, старый файл 21 сохраняется.

Запись идёт только когда карта свободна: нет события, сообщения, перехода и затемнения, игрок стоит, сохранение разрешено.

- После перехода на другую карту, не чаще чем раз за окно паузы.
- После общего события сна, без паузы.
- Перед боссом (переключатель 15 или уникальный враг из `NP_BossBalance`), до старта общего события 31. Загрузка такого файла снова начинает бой и сразу второе автосохранение не пишет.

В галерее и в бою записи нет. Короткая всплывающая подсказка сообщает, что сохранение прошло. Команды: `NP_AutoSave now`, `NP_AutoSave on`, `NP_AutoSave off`.

## Порядок загрузки

После `NP_VideoPortrait`, перед `NP_QuestMarker`. От `NP_SaveThumb` не зависит: тот плагин эти слоты не меняет.

## Параметры

- **Enabled** `true` — пункт в настройках, по умолчанию включено.
- **Slot Id** `21` — первый из двух файлов. Если номер не больше числа ручных слотов (20), берётся `maxSavefiles()+1`.
- **Throttle Seconds** `60` — минимум игрового времени между автосохранениями после перехода.
- **Sleep Common Events** `325` — события сна, после которых запись идёт сразу, без паузы.
- **Idle Frames** `20` — карта должна столько кадров быть свободной.
- **Slot Label** `Автосохранение`, **Toast Text** `Автосохранение…`, **Option Label** `Автосохранение`. Пустая подсказка прячет всплывашку. Пустое имя пункта прячет строку в настройках.

## Установка

Скопируйте `NP_AutoSave.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_AutoSave.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_AutoSave/` в этом репозитории. Папка нужна, чтобы скрипт и описание было удобно смотреть на GitHub и позже вынести в отдельный git submodule.
