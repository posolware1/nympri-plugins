# NP_RareMobs

## Название

Тринадцать редких элит, бестиарий и разовая добыча.

## Версия

1.0 (константа скрипта). В `@plugindesc` номер не повторён. `NP_EliteMobs` позже поднимает бросок каждого вида, включая эти, до 25%.

## Назначение

Когда подземелье копирует одного из 13 базовых монстров с карты-шаблона, первый подходящий символ после входа на карту может стать редким. Исходный шанс 4–6% по виду и не больше одного редкого за вход. Бросок запоминается один раз на карту и день. После убийства (или побега крысы-воришки) этот вид в тот день больше не появляется.

У редкого звезда в имени, перекрашенный исходный спрайт и свечение. HP ×1.5 / 2 / 2.25 / 2.5 для Фапа / Лёгкой / Нормы / Сложной, опыт удвоен, эро-захват выключен, сон и оглушение сопротивляются, один супер снимает не больше половины макс. HP.

Тринадцать видов, коротко о бое:

- Крыса-воришка — крадёт золото и убегает; сон или оглушение её держат.
- Королева пчёл — рой режет урон, пока его не разгонят огнём или супером; только днём.
- Седой вожак — вой с предупреждением копит урон; только ночью.
- Медведь-шатун — ниже половины HP предупреждает и бьёт дважды; только ночью. Коготь без договора с Яризо становится 600 G.
- Чумной знахарь — объявленная склянка; защита разбивает её, Зельеварка может поймать.
- Гнолл-знаменосец — броня копится, пока тяжёлый удар или супер не сломает знамя.
- Янтарный голем — корка, которую колют магия, огонь или супер.
- Королевский мармелад — лечится, пока не ударят водой или магией; кислота портит облачение жрицы. Особенность в бестиарии видна после встречи.
- Грозовой Райдзю — разряд на третьем ходу; супер крадёт заряд.
- Сердце пламени — ближний бой снимает HP атакующему, вода ранит сильнее, может взорваться.
- Клинок-отступник — пьёт заряд супера и контратакует, если его не ранили.
- Ночной латник — высокая броня, слаб к святому, каждый удар снимает жрице 1 напряжения; только ночью.
- Болотный утопленник — хватка, которую сбивает удар союзника, и напряжение отряду каждый ход; только ночью.

Каждое убийство даёт золото и тройные базовые материалы плюс бонус вида. Редкая вещь (12–30%) падает один раз на вид; сильнейшие требуют уровень подземелья от 3. Дальше этот вид платит только золотом, опытом и материалами. Вещи ищутся по метке `<NP_ITEM:key>` из `NP_Items`.

Меню **Бестиарий редких**: невстреченные виды — силуэты `???`, но с текстом и косвенной приметой. Встреченные показывают перекрашенный спрайт, место, число убийств и (у мармелада) механику. Добыча — пульсирующий силуэт, пока не выпадет, затем настоящая иконка и имя.

## Порядок загрузки

После `NP_BossBalance`, перед `NP_MorningHints`. `NP_EliteMobs`, `NP_EliteRewards` и `NP_EliteSprites` должны стоять после этого скрипта и после `NP_Items`. Пункт **Редкие враги**, по умолчанию включён.

## Параметры

Параметров в менеджере плагинов нет. Пункт настроек — выключатель. Выключено: нет редких появлений, нет их механик и нет лишней добычи. Бестиарий остаётся читаемым.

## Требования

Windows, **Alpha 0.80j**. Из скачанного ZIP запустите `install.bat` и укажите папку `www` игры. Категории в общем README — не порядок загрузки.

## Установка

Скопируйте `NP_RareMobs.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_RareMobs.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_RareMobs/` в этом репозитории.

## Скриншоты

Снимка нет. У плагина нет своего экрана, либо в отобранных кадрах его не видно. Позже сюда можно положить только настоящий кадр игры, не макет.
