# NP_StoryHint

## Название

«Что дальше» по основной истории и где кончается версия 0.80j.

## Версия

1.0 (`@plugindesc`).

## Назначение

Короткая подсказка, какой шаг основной истории следующий. В таблице 53 шага, проверка идёт от конца истории к началу. Берётся первый шаг, чьё условие совпало. Каждое условие читается отдельно; сломанная строка пропускается.

На вкладке **Сюжет** подсказка закреплена сверху, заголовок **Что дальше** (по-английски **What's next**). Язык берётся из `NP_Language`. Если этой вкладки нет, та же команда появляется в главном меню и открывает простое окно. Всплывающих окон и отдельных советов нет.

Последний шаг версии 0.80j говорит, что основная история здесь заканчивается, а побочные задания и свободная игра продолжаются. Два более ранних обрыва (линия Ирис и таверна в городе в пустоши) говорят так же, если их переменные уже так высоки.

После главы 1 подсказка говорит, что встреча с Леоном у корабля в этой версии может не начаться: его страница есть только на первом шаге сюжета церкви. После разговора с мудрецом подсказка говорит, что следующий официальный квест сам не начинается. Эти два места здесь не чинятся.

Пока сюжетные переменные ещё не записаны, подсказка — найти выход из комнаты в руинах.

## Порядок загрузки

После `NP_QuestTabs`, перед `NP_AudioBalance`. Пункт настроек раскладывает `NP_OptionsCategories`, он остаётся последним.

## Параметры

Параметров в менеджере плагинов нет. Пункт настроек **Что дальше / What's next**, категория «Интерфейс», по умолчанию включён. Выключенный пункт прячет подсказку и команду меню.

## Требования

Windows, **Alpha 0.80j**. Из скачанного ZIP запустите `install.bat` и укажите папку `www` игры. Категории в общем README — не порядок загрузки.

## Установка

Скопируйте `NP_StoryHint.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_StoryHint.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_StoryHint/` в этом репозитории.

## Скриншоты

Снимка вкладки «Сюжет» с этой подсказкой пока нет.
