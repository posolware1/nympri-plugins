# NP_EliteRewards

## Название

Шесть трофеев новых редких.

## Версия

1.0 (`@plugindesc`).

## Назначение

Правила выпадения и «один трофей на сохранение» остаются в `NP_RareMobs`. Этот скрипт описывает, что трофей делает на персонаже:

- **Компас следопыта** читает редких, которые уже помечены на карте. Новых не бросает.
- **Линза ответного удара** запоминает +1 к попаданию после промаха обычной атаки. Следующая попытка это тратит.
- **Двойное жало** даёт +1 урона до брони на каждом втором успешном обычном ударе. Крит и слабость это не умножают. Промах счётчик не двигает. Снятие сбрасывает его.
- **Споровый футляр:** лечебный предмет, который реально лечит, даёт цели барьер на 2 HP против одного прямого удара. Не складывается. Два срабатывания на владельца за бой, барьер гаснет в конце следующего хода врага. Возврат предмета барьер не наполняет.
- **Камертон сумерек** цепляется к текущему опасному объявлению одного из шести новых элит. Когда это объявление действительно бьёт, каждая цель получает на 2 меньше (минимум 1). Одно исполнение на владельца за бой. Прерванное объявление ничего не тратит.
- **Капля резерва** смотрит платные лечебные умения, которые реально вернули HP: считает потраченную MP и перелечение по целям, которые не были полны. На 2 MP и 3 перелечения возвращает 1 MP, один раз за бой. Лечение отряда платит один раз. Предметы, регенерация, вампиризм, бесплатные касты и полные цели не считаются.

## Порядок загрузки

После `NP_Items` и `NP_EliteMobs`, перед `NP_EliteSprites`. Записи дописываются до того, как YEP Item Core фиксирует длины базы. Занятый зарезервированный id останавливает запуск, а не ставит награду наполовину.

## Параметры

Параметров в менеджере плагинов нет. Зарезервированные id: оружие 701 «Двойное жало»; броня 1000 «Компас следопыта», 1001 «Линза ответного удара», 1002 «Споровый футляр», 1003 «Камертон сумерек», 1004 «Капля резерва».

## Требования

Windows, **Alpha 0.80j**. Из скачанного ZIP запустите `install.bat` и укажите папку `www` игры. Категории в общем README — не порядок загрузки.

## Установка

Скопируйте `NP_EliteRewards.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_EliteRewards.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_EliteRewards/` в этом репозитории.

## Скриншоты

Снимка нет. У плагина нет своего экрана, либо в отобранных кадрах его не видно. Позже сюда можно положить только настоящий кадр игры, не макет.
