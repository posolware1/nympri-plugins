# NP_FastBattle

## Название

Ускоренный бой по желанию.

## Версия

1.0 (`@plugindesc`). В настройках по умолчанию выключен.

## Назначение

При включённой опции и переключателе 14 ускоряется только боевая механика:

- Команды ожидания (и `this.wait` в скрипте) умножаются на коэффициент.
- «Показать анимацию» больше не ждёт конца ролика.
- Пустые «Показать текст» — немые паузы журнала — листаются сами.
- Картинки кубиков пропускаются.

Всё, чего нет в этих списках, по-прежнему ждёт игрока: сообщения с лицом или текстом, выборы, эро-действия в бою, строки приставаний, обучение, нокдаун союзника и поражение. Команда: `NP_FastBattle on` или `off`.

## Порядок загрузки

После `NP_QuestMarker`, перед `NP_TitleProgress`. Это не `NP_BattleQoL` (×2 по Shift). Оба можно включить вместе. `NP_Voice` укорачивает фразы, если в бою включён этот пункт.

## Параметры

- **Enabled** `false` — подпись в настройках **Быстрый бой**.
- **Battle Switch** `14` — переключатель «идёт бой».
- **Wait Rate** `0.25` — ожидания в боевой механике становятся вчетверо короче, минимум 1 кадр.
- **Auto Advance Frames** `14` — пустые паузы журнала длятся столько кадров вместо нажатия.
- **Hide Dice** `true` — картинки `dice1`–`dice6` и `diceN_red` не показываются. Бросок остаётся в журнале.
- **Battle Common Events** и **Battle Map Event Pages** — только эти интерпретаторы ускоряются. По умолчанию это чистые боевые общие события и страницы карты 53 `9:2` и `9:4`.

## Установка

Скопируйте `NP_FastBattle.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_FastBattle.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_FastBattle/` в этом репозитории. Папка нужна, чтобы скрипт и описание было удобно смотреть на GitHub и позже вынести в отдельный git submodule.

## Скриншоты

Отдельного экрана этот плагин не добавляет.
