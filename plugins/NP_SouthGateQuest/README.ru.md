# NP_SouthGateQuest

## Название

Необязательная доставка бумаг гильдии на южную заставу.

## Версия

В `@plugindesc` номера нет.

## Назначение

Дополнительная услуга гильдии на карте 13, событие 12, страница 2, предлагает доставку, когда ранг игрока 2 или выше. Карта 241 — закрытая застава (события 8 и 9) и, после открытия, стража (события 3 и 10). Исходное поведение ворот, ранга и сюжета на этих картах остаётся.

Сдача бумаг платит ровно 200 G. Общие события 46 и 47, обычная выдача награды, не вызываются, поэтому нет ни опыта, ни славы. Задание необязательное.

## Порядок загрузки

После `NP_BondHints`, перед `NP_RemovedQuestCompat`. Добавлено после прохода перевода CSV. Исходные строки CSV и файлы карт не подменяет.

## Параметры

Параметров в менеджере плагинов нет. Задание 201091, переменная этапа 3571 (0, 1 или 99), ключевой предмет 2950.

## Установка

Скопируйте `NP_SouthGateQuest.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_SouthGateQuest.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_SouthGateQuest/` в этом репозитории. Папка нужна, чтобы скрипт и описание было удобно смотреть на GitHub и позже вынести в отдельный git submodule.

## Скриншоты

Отдельного экрана этот плагин не добавляет.
