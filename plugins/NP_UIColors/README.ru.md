# NP_UIColors

## Название

Одна тёмная палитра на все окна.

## Версия

В `@plugindesc` номера нет.

## Назначение

CSV и база не переписываются. Цвет ставится в момент отрисовки окна.

- Ролевая палитра (`NP_UIColors.ROLES`) и коды `\c[900+n]`, чтобы другие плагины могли просить `lust`, `stress` и остальные роли по имени.
- Обычные индексы `\c[n]` переназначаются во всех окнах, кроме окна сообщения, выбора и бегущего текста. Там остаются цвета сцены.
- Имена предметов из YEP Item Core зависят от вида предмета и качества экипировки. Ранг брони берётся из ценовых полос. Явная ненулевая заметка `<Text Color: x>` всё равно побеждает.
- Заголовки заданий разные для сюжета, побочных и обучения. Выполненные серые. Награды, строка подсказки и звёзды берут цвета палитры.
- Стрелки сравнения в лавке используют цвета усиления и ослабления.

## Порядок загрузки

После `YEP_ItemCore`, `KNS_QuestBase`, `NP_QuestHints`, `NP_QuestTabs` и `NP_ShopCompare`. В списке мода после `NP_AudioBalance` и перед `NP_LogToggle`. До `NP_OptionsCategories`. Выключено — исходная палитра.

## Параметры

Параметров в менеджере плагинов нет. Пункт **Цветное оформление**, раздел «Интерфейс».

## Установка

Скопируйте `NP_UIColors.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_UIColors.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_UIColors/` в этом репозитории. Папка нужна, чтобы скрипт и описание было удобно смотреть на GitHub и позже вынести в отдельный git submodule.
