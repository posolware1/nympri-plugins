# NP_OriginalBugFix

## Название

Патчи крашей скриптов оригинала и переходов на отсутствующие карты.

## Версия

1.1 (`@plugindesc`).

## Назначение

При загрузке карты или списка общих событий каждая известная команда сверяется с хэшем исходного текста. Совпало — подставляется исправленный JavaScript. Не совпало — пропуск и одна строка в консоли. Повторно та же команда не меняется.

Команды показа текста не правятся, поэтому языковой патч по-прежнему может заменять реплики.

Переход на карту, которой нет в списке карт, не выполняется. Игрок видит короткую фразу и возвращается на карту мира (карта 3 по `$WMTS`, или карта 96, клетка 7,18, если этой точки нет). Переход на карту 251 на клетку за краем сжимается в 29,39.

Две булавки карты мира теперь ведут в уже существующий город. Горгода (`V334` равна 3, отсутствующая карта 385) открывает карту 217, клетка 5,37. Точка внутри улицы 120×50, соседние карты уже используют её как вход. Заброшенная хижина (`V334` равна 37, карта 157 в 21,85 — это за краем пустой карты) открывает карту 155, клетка 16,21. Точка внутри хижины 35×30. Направление и затухание остаются теми, что были в исходной команде. Любая другая отсутствующая карта, в том числе 157, когда переменная 334 не равна 37, по-прежнему блокируется. Новые карты не добавляются.

В выборе ночлега `en(v[133])` становится `en(s[133])`, если эта строка ещё на месте. Файлы патчей 202609 и 202610 целиком не применяются, `CommonEventPatchList` остаётся пустым.

В сейв ничего не пишется.

## Порядок загрузки

Сразу после `NP_Language`, перед `NP_VideoPortrait` и остальными игровыми плагинами. Пункт настроек раскладывает `NP_OptionsCategories`, он остаётся последним.

## Параметры

Параметров в менеджере плагинов нет. Пункт **Исправления оригинала / Original bug fixes**, категория «Прочее», по умолчанию включён. Выключенный пункт пропускает следующую загрузку данных и сторож переходов.

## Требования

Windows, **Alpha 0.80j**. Из скачанного ZIP запустите `install.bat` и укажите папку `www` игры. Категории в общем README — не порядок загрузки.

## Установка

Скопируйте `NP_OriginalBugFix.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_OriginalBugFix.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_OriginalBugFix/` в этом репозитории.

## Скриншоты

Отдельного экрана этот плагин не добавляет.
