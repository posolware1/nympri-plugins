# NP_RemovedQuestCompat

## Название

Совместимость сейвов после трёх отменённых заданий.

## Версия

Номера нет. `@plugindesc` называет это только совместимостью сохранений.

## Назначение

Нет текста задания, диалога, графики, награды и нового события карты. На картах, где от первой версии тех заданий остались сироты, скрипт убирает сироту, если он совпал с известной ролью или с известным пустым слотом (карта, id события, позиция и картинка персонажа). Настоящий префаб и текущий статичный NPC остаются.

Интерпретаторы, которые ещё крутят удалённые события, останавливаются. Записи навигатора на эти три id очищаются, когда в списке заданий их уже нет. В справке прямо сказано, что игрового контента здесь нет.

## Порядок загрузки

После `NP_SouthGateQuest`, перед `NP_OptionsCategories`. Сейвы не записывает.

## Параметры

Параметров в менеджере плагинов нет. Id заданий, которые убираются из навигатора, если их уже нет в списке: 201092, 201093, 201094.

## Требования

Windows, **Alpha 0.80j**. Из скачанного ZIP запустите `install.bat` и укажите папку `www` игры. Категории в общем README — не порядок загрузки.

## Установка

Скопируйте `NP_RemovedQuestCompat.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_RemovedQuestCompat.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_RemovedQuestCompat/` в этом репозитории.

## Скриншоты

Снимка нет. У плагина нет своего экрана, либо в отобранных кадрах его не видно. Позже сюда можно положить только настоящий кадр игры, не макет.
