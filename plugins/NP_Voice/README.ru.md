# NP_Voice

## Название

Короткие голосовые куски из уже существующих дорожек.

## Версия

1.1 (`@plugindesc`).

## Назначение

Новых голосовых файлов нет. Плагин режет уже существующие дорожки `audio/bgs/!voice_moan1.ogg` и `audio/se/!voice_cumming1.ogg`, берёт случайный кусок из пула, слегка меняет высоту и сглаживает края. Одновременно звучит одна фраза; новая обрывает старую.

Пулы: `sigh` (вздохи), `gasp` (короткий вдох), `moan` (стон) и `light` (пляж, без стонов). Пулы можно смешивать (`moan|sigh`). Громкость выровнена с оригинальными сценами и затем умножается на громкость SE. `muffle` глушит кусок, как из-за двери, а `at=X,Y` ставит панораму и спад по расстоянию от игрока.

События и другие плагины вызывают `NPVoice <пул>` или `NPVoice.play(...)`. `NPVoice stop` обрывает текущую фразу. При выключенной опции эти вызовы молчат.

## Порядок загрузки

После `NP_PriestessDiary`, перед `NP_SaveThumb`. Его вызывают другие скрипты (`NP_OutfitReact` берёт пул gasp). Новых звуковых файлов нет.

## Параметры

- **Enabled** `true` — подпись **Озвучка добавок**.
- **Fast Battle Max** `0.7` — максимальная длина фразы в секундах, если идёт бой и включён «Быстрый бой».

## Требования

Windows, **Alpha 0.80j**. Из скачанного ZIP запустите `install.bat` и укажите папку `www` игры. Категории в общем README — не порядок загрузки.

Берёт два звука, которые уже есть в игре: `audio/bgs/!voice_moan1.ogg` и `audio/se/!voice_cumming1.ogg`. Этот набор их не распространяет.

## Установка

Скопируйте `NP_Voice.js` в `www/js/plugins/` игры. Имя файла должно остаться `NP_Voice.js`. В менеджере плагинов включите его в порядке из раздела [Порядок загрузки](#порядок-загрузки). RPG Maker MV читает плагины из `www/js/plugins/`, а не из папки `plugins/NP_Voice/` в этом репозитории.

## Скриншоты

Проигрывает короткий вздох, вдох или стон из звука, который уже есть в игре. На снимке этого не слышно. Переключатель — обычная строка в настройках.
