# Older in-game frames

Sixteen frames selected from earlier captures. They show the UI that was on screen at the time. They are not a new shoot of this revision, and they are not proof that a clean game launch passed.

Plugin pages link here when the same frame shows more than one plugin. A shared frame only supports what is visible: a menu row is not a completed attack, and a corner icon is not a full screen of that plugin.

Do not add mockups or explicit images to this folder.
